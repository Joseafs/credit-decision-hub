# Credit Decision Hub

Plataforma full-stack para acompanhamento e análise de propostas de crédito, criada como projeto de estudo e portfólio.

O projeto será desenvolvido como um monorepo com React, Node.js, MongoDB, Databricks, Terraform e Turborepo.

## Contexto do projeto

A especificação compartilhada, decisões, regras e orientações para agentes estão centralizadas em [`context/README.md`](./context/README.md).
